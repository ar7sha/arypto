# Contributing to Arypto 🦀

Wanna help? Cool. Here's the deal.

## Rules (there are like 4)

1. **Open an issue first.** Don't just dump a 500-line PR on me.
2. **Keep it small.** One thing per PR. No "rewrote everything" PRs.
3. **`cargo build` must pass.** If it doesn't compile, it's not a contribution, it's a crash report.
4. **Be cool.** This is a fun project, not a job.


## What I'll probably merge

- Bug fixes 🐛
- Security improvements 🔐
- New ciphers (with docs, please)
- Better errors/messages
- Docs fixes

## What I'll probably close

- Huge refactors "because cleaner"
- Random dependencies



## Found a security bug?

Open an issue.

## Style

PLEASE `cargo fmt` before committing. That's it.

Now go break something. 🚀
